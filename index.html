Dev Essentials

Fast, friendly command-line tools for searching, filtering, and exploring code on macOS.

Install

curl -fsSL https://dev.kenlsm.com/install.sh | bash

Paste that into a macOS Terminal. Run it again at any time to update.

To install the tools without changing ~/.zshrc:

curl -fsSL https://dev.kenlsm.com/install.sh | DEV_ESSENTIALS_SKIP_ZSHRC=1 bash

What does it do?

  1. Installs HomebrewOnly if it is missing.
  2. Installs the toolsEverything in the Brewfile, skipping what you already have.
  3. Sets up Zshfzf uses fd with bat and eza previews, man pages use bat, and zoxide is enabled. Your ~/.zshrc is backed up first.
  4. Shows a summaryWhat was installed, what you already had, and where to read more.
